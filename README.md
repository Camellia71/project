浏览器历史记录栈
浏览器维护着一个历史记录栈（history stack），记录用户访问过的页面：
```tsx
访问顺序: 登录页 → 主页
历史记录栈: [登录页, 主页]  ← 当前位于主页
```
可以按"返回"按钮回到登录页
当使用 replace: true时：
```tsx
// 假设当前在登录页，用户登录成功后
navigate('/', { replace: true });

// 效果：
// 历史记录栈: [主页]  ← 用主页"替换"了登录页
// 而不是：[登录页, 主页]
```
